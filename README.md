# IRON SOL Better Controls

This simple program allows you to set two macro keys that are essentially a "better" version of the jump and ability keys in the game. You can download it in the [releases tab](https://github.com/zWolfrost/IRON-SOL-Better-Controls/releases/latest).

To set it up, simply edit the `config.toml` file found in the zip folder using a text editor and fill in the keys following the instructions; Then, execute the `.exe` file.

Its code is open source and extremely short (<100 lines) so you can easily examine it.

No AI was used in the development process.
